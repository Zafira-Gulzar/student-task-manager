# Student Task Manager

A collaborative web application developed as part of a Git & GitHub assignment. The Student Task Manager allows users to add, display, complete, delete, and search tasks efficiently.

## Features

- ➕ Add new tasks with title and description
- 📋 Display all tasks as interactive cards
- ✅ Mark tasks as completed (with Undo option)
- 🗑️ Delete tasks from the list
- 🔍 Real-time search and filter tasks by title/description
- 📊 Live statistics panel (Total / Completed / Pending)
- 📱 Responsive design for mobile and desktop

## Git Workflow

This project followed a professional collaborative Git workflow:

1. **Repository Initialization** — Local repo created and pushed to GitHub.
2. **Branching Strategy** — Feature branches for each task (`feature/task-form`, `feature/task-style`, `feature/task-search`).
3. **Commits** — Meaningful commit messages for every change.
4. **Pull Requests** — Each feature was submitted via PR and reviewed by the other team member.
5. **Code Reviews** — Comments and approvals before merging.
6. **Merge Conflicts** — Created and resolved intentionally on `README.md`.
7. **Git Recovery Commands** — Demonstrated `stash`, `restore`, `reset`, and `revert`.
8. **Tagging & Release** — Tagged `v1.0.0` and published a GitHub Release.
